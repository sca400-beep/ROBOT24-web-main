## 🚀 Getting Started

### Installation
Run `npm i` to install all project dependencies:
```bash
npm install
```

### Development
Run `npm run dev` to start the local development server:
```bash
npm run dev
```

### Build
Run `npm run build` to build the production bundle:
```bash
npm run build
```
